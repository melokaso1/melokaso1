## 👨🏻‍💻 Sobre mí

Soy desarrollador de software de **Bucaramanga, Colombia** 🇨🇴. Trabajo en la creación de soluciones prácticas, mantenibles y orientadas a resolver necesidades reales, participando en el ciclo completo de una aplicación: análisis, modelado de datos, lógica de negocio, APIs, interfaces web, integración de servicios, pruebas funcionales y documentación técnica.

Mi enfoque principal está en el desarrollo **backend con C# y .NET**, arquitectura de software, diseño de bases de datos relacionales y construcción de aplicaciones full-stack con TypeScript. He trabajado y participado en proyectos de salud, odontología, inventario, gestión mecánica, transporte, automatización y aplicaciones web.

```text
💻 Backend .NET       → APIs REST, lógica de negocio y persistencia
🗃️ Bases de datos     → Modelado relacional, SQL, consultas y migraciones
🏗️ Arquitectura       → Clean Architecture, repositorios y Unit of Work
🌐 Full-Stack         → Integración de frontend, backend y servicios
🧪 Calidad            → QA funcional, pruebas de vistas y endpoints
🤖 Automatización/IA  → Chatbots, flujos de trabajo e integración de APIs
```

- 🔭 Desarrollo y participo en sistemas de salud, odontología, inventario, gestión mecánica, transporte y automatización.
- ⚙️ Trabajo con C#, .NET, ASP.NET Core, Entity Framework Core, SQL, TypeScript y APIs REST.
- 🧠 Me interesan la arquitectura de software, el diseño de datos, QA, documentación técnica y la integración de IA.
- 🌱 Continúo fortaleciendo mi experiencia con Clean Architecture, PostgreSQL, Oracle, pruebas e integración de servicios.
- ⚡ Disfruto resolver problemas técnicos y construir productos con una base sólida.
