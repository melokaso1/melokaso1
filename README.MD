## 👨🏻‍💻 Sobre mí

Soy estudiante de programación y desarrollador en formación de **Bucaramanga, Colombia**. Me enfoco en comprender cómo se construyen aplicaciones completas: desde el modelado de datos y la lógica de negocio, hasta APIs, interfaces web, pruebas y documentación técnica.

Actualmente estoy fortaleciendo mi perfil en desarrollo **backend con C# y .NET**, diseño de bases de datos relacionales, arquitectura limpia, integración de APIs y desarrollo frontend con TypeScript. Me gusta trabajar en proyectos prácticos donde pueda convertir una necesidad real en una solución organizada, mantenible y funcional.

- 🔭 Trabajo en proyectos de gestión, inventarios, salud, automatización y plataformas web.
- 🌱 Profundizando en ASP.NET Core, Entity Framework Core, Clean Architecture y APIs REST.
- 🧠 Interesado en bases de datos, patrones de diseño, QA, automatización e integración de IA.
- 🧩 Me importa que el código sea claro, que el modelo de datos tenga sentido y que la aplicación resuelva un problema real.
- ⚡ También disfruto aprender mediante proyectos, depurar errores y mejorar soluciones existentes.
